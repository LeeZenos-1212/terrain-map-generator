# 随机等高线地形图生成器

一个使用 Python 生成随机高度场，并将其渲染为现代、简洁、具有精细地形阴影的等高线地图项目。

项目初期只关注纯地形生成。城市、道路、功能分区和交互界面暂不实现，但会通过模块化的数据结构为后续扩展保留空间。

## 项目目标

- 根据随机种子生成可复现的二维地形。
- 输出可继续处理的原始高度场，而不只是一张最终图片。
- 生成清晰的等高线、自然的山体阴影和低饱和度地形配色。
- 将地形生成与地图渲染分离，方便后期更换风格。
- 保持各类地貌算法独立，后续可逐步加入山脊、空间扭曲和侵蚀。

## 第一阶段暂不包含

- 城市和建筑生成
- 道路与交通网络
- 功能分区与城市规划
- 资源、人口和经济模拟
- Web 交互地图
- 完整的真实地理坐标系统

## 技术路线

```text
随机种子与参数
      ↓
多尺度噪声生成
      ↓
高度场塑形与归一化
      ↓
地形分析（坡度、坡向、阴影）
      ↓
等高线与地形渲染
      ↓
保存原始数据和地图图片
```

建议使用的基础技术：

- Python 3.11+
- NumPy：高度场与数组运算
- SciPy：平滑、滤波及后续地形处理
- Matplotlib：等高线、山体阴影和图片输出
- perlin-numpy：二维 Perlin 与分形噪声生成

参考项目：

- [pvigier/perlin-numpy](https://github.com/pvigier/perlin-numpy)
- [dandrino/terrain-erosion-3-ways](https://github.com/dandrino/terrain-erosion-3-ways)

### 阶段 1：基础高度场生成

目标：使用多尺度噪声生成可复现的基础地形。

任务：

- [ ] 接入二维 Perlin 或分形噪声。
- [ ] 支持随机种子。
- [ ] 支持分辨率、基础频率和噪声层数配置。
- [ ] 支持 `octaves`、`persistence` 和 `lacunarity` 参数。
- [ ] 将输出归一化到 `0.0 ~ 1.0`。
- [ ] 使用 `float32` 保存高度场，控制内存和文件大小。
- [ ] 将原始高度场保存为 `.npy`。

产物：

- `output/<seed>/heightmap.npy`
- 基础灰度高度图预览

验收标准：

- 相同种子和参数生成完全相同的高度场。
- 不同种子能够生成明显不同的结果。
- 高度场中不存在 NaN 或无限值。

### 阶段 2：基础等高线地图

目标：将高度场渲染成清晰、可用的等高线地图。

任务：

- [ ] 绘制基础分层设色图。
- [ ] 根据固定间距或固定数量生成等高线。
- [ ] 支持普通等高线和加粗主等高线。
- [ ] 支持隐藏坐标轴、边框和多余留白。
- [ ] 输出可配置尺寸和 DPI 的 PNG。
- [ ] 保证生成过程与渲染过程相互独立。

产物：

- `output/<seed>/contours.png`
- `output/<seed>/terrain_color.png`

验收标准：

- 等高线连续、清晰且没有明显锯齿。
- 修改颜色和线宽时不需要重新生成高度场。
- 高清输出不会因画布尺寸变化而破坏比例。

### 阶段 3：精细地形阴影

目标：形成现代地图风格的细腻地貌表现。

任务：

- [ ] 根据坡度和坡向生成基础 Hillshade。
- [ ] 支持光源方向和高度角配置。
- [ ] 实现多方向山体阴影，减弱单一光源造成的黑块。
- [ ] 将阴影与低饱和地形配色混合。
- [ ] 控制等高线在阴影地形上的可读性。
- [ ] 准备浅色和深色两套基础主题。

产物：

- `output/<seed>/hillshade.png`
- `output/<seed>/terrain_map.png`

验收标准：

- 山脊、山谷和坡向能够被直观辨认。
- 阴影保留细节，同时不会出现大面积死黑区域。
- 地形阴影、底色和等高线的层次清楚。

### 阶段 4：地貌塑形模块

目标：减少普通噪声的重复感，生成更有方向性和结构性的地形。

任务：

- [ ] 添加高度曲线调整，控制平原、丘陵和高山比例。
- [ ] 添加山脊噪声模块。
- [ ] 添加 Domain Warping 空间扭曲。
- [ ] 支持不同噪声结果按权重混合。

- [ ] 提供山谷、山地、群岛等预设参数。

验收标准：

目标：在不引入复杂世界模拟的情况下，提高地形的自然感。

验收标准：

- 侵蚀能够形成更自然的沟谷和坡面。

## 建议的首个里程碑

首个可用版本只包含阶段 0 至阶段 3：

1. 输入随机种子和基础噪声参数。
2. 生成并保存二维高度场。
3. 绘制低饱和度分层设色。
4. 添加多方向山体阴影。
5. 叠加普通等高线和主等高线。
6. 输出原始数据与高清 PNG。

完成该里程碑后，再根据实际视觉效果决定优先加入山脊、空间扭曲还是侵蚀，避免过早增加复杂度。

## 设计原则

- 数据优先：高度场是核心产物，图片只是其中一种表现形式。
- 生成与渲染分离：改变风格不应重新生成地形。
- 参数可复现：所有随机过程必须受种子控制。
- 模块可组合：每个地貌处理步骤可以独立开关和测试。
- 逐步增加复杂度：先做好地形与阴影，再考虑侵蚀和其他地图要素。
- 保持现代视觉方向：配色简洁、层级明确、细节丰富但不过度装饰。
