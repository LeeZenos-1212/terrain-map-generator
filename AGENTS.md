# Project Instructions

## GitHub publishing

- Do not automatically push changes to GitHub.
- After completing a substantial change, ask the user whether the current changes should be committed and pushed.
- Treat completion of a development phase, a multi-file feature, a dependency change, a public interface change, or a significant project-structure change as a substantial change.
- Small documentation corrections and minor formatting changes do not require a push prompt unless the user explicitly asks for one.
- Before every push, summarize the files changed, the validation performed, and the proposed commit message.
- Push only after the user explicitly confirms that specific push.
